# Real Estate Intelligence Demo

This folder currently contains the product definition and implementation backlog for an [AppKit v0](https://developers.databricks.com/docs/appkit/v0) Databricks demo combining agents, Lakebase search, and geospatial listing exploration.

- [Product requirements](PRD.md)
- [Issue breakdown](ISSUES.md)
- [AppKit application](application/README.md)

The proposed dataset is one synthetic `listings` table with 300 rows by default and a hard maximum of 499 rows. Implementation is intentionally left to the issues in the backlog.
